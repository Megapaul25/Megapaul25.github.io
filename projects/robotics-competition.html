Overview

As part of the EPFL Interdisciplinary Robotics Competition 2026, I worked in a three-person team (Team ROBZ, Group 4: Arnaud Buchel, Jan Juraszek, and Paul Huot-Marchand)[cite: 1] to develop an autonomous robot capable of navigating an arena with multiple scoring zones (Zone 1 to Zone 4)[cite: 5], handling obstacles[cite: 6], and completing a sequence of tasks[cite: 6].

My main responsibility was the high-level software[cite: 7], from visual perception and beacon-based localization[cite: 17, 30] to navigation[cite: 7] and autonomous mission execution[cite: 7].

My Contributions

Computer Vision

Implemented local visual perception using RGB camera processing to extract target features, detect arena corner beacons, and support real-time autonomous decision making[cite: 14, 17].

Localization

Developed the global beacon-based triangulation algorithm (solving circle intersections from relative angles $\theta_{AB}$ and $\theta_{BC}$)[cite: 29, 30] combined with an Extended Kalman Filter (EKF) sensor fusion[cite: 16] to estimate the robot's pose[cite: 16].

Navigation

Implemented path planning using the A* algorithm[cite: 7] and integrated navigation decision-making directly into the robot's high-level controller[cite: 7].

Mission Execution

Structured the autonomous behavior as a Finite State Machine (FSM) coordinating perception, navigation, piece-collecting mechanisms, and task execution[cite: 7].

Technical Implementation

The high-level software ran in Python on a Raspberry Pi Single Board Computer (SBC) handling vision and path planning[cite: 7, 18], communicating via serial interface with an ESP32 microcontroller for low-level motor control and sensor monitoring[cite: 7, 17].

  • Modular software architecture written in Python running on Raspberry Pi[cite: 7, 18].
  • Camera-based visual perception for target detection and beacon landmark triangulation[cite: 14, 17, 30].
  • Extended Kalman Filter (EKF) combining wheel encoders and optical measurements for drift-free localization[cite: 14, 16].
  • A* algorithm for optimal path planning across arena zones[cite: 5, 7].
  • Finite-State-Machine (FSM) orchestrating mission logic, grabbing, storage, and trapdoor releasing[cite: 7, 26, 28].
  • Serial communication protocol between the Raspberry Pi SBC and the ESP32 low-level MCU[cite: 7, 17, 18].

Results

Our team (ROBZ) finished 1st place in the EPFL Interdisciplinary Robotics Competition 2026[cite: 1].

The project provided hands-on experience in system architecture decomposition[cite: 7], sensor fusion[cite: 16], real-time vision processing[cite: 14], and hardware-software integration under competitive constraints[cite: 1, 5, 8].
